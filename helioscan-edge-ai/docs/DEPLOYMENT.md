# Deployment on the Arduino UNO Q

## What you need

- The Arduino UNO Q, set up in **Arduino App Lab** and connected to Wi-Fi **with internet access**
  (the first run downloads the Python packages: NumPy, OpenCV, ONNX Runtime).
- The phone on the **same network** as the board. The simplest setup: turn on the phone's hotspot
  and connect the UNO Q to it.
- The printed C14 panel (6 sheets taped together, white margins trimmed at the crop marks) on a
  light surface.

## 1. Build the app archive

On the computer, from the `helioscan-edge-ai` folder:

```bash
python tools/package_app.py
```

This creates `dist/helioscan-edge.zip` (app.yaml, python/, sketch/, assets/, with the trained
model `python/models/helioscan_yolo11n.onnx`).

## 2. Import it in App Lab

1. Open Arduino App Lab and select the UNO Q.
2. In **My Apps**, import `dist/helioscan-edge.zip` (App Lab accepts ZIP archives with `app.yaml` at
   the root or inside one top-level folder, which is the case here).
3. Open the app and press **Run**. The first run takes a few minutes: App Lab installs the packages
   listed in `python/requirements.txt` and flashes the sketch to the microcontroller.
4. The console shows a line starting with `model YOLO11n (Ultralytics), fine-tuned` when the
   pipeline is ready. The built-in LED stays off until a scan starts.

**Fallback (manual copy):** create a new app in App Lab named `helioscan-edge`, then copy the
content of the `app/` folder into it over SSH (VS Code Remote-SSH or `scp`). The apps folder is in
the `arduino` user's home on the board (`/home/arduino/ArduinoApps/` on current images; check on
your board).

## 3. Connect the phone

1. Find the board's IP address: App Lab shows it in the board panel, or run `hostname -I` in the
   board terminal.
2. On the phone, open **`https://<board-ip>:7000`** (HTTPS is required for the camera).
3. Accept the certificate warning (self-signed certificate generated by the board):
   Chrome *Advanced → Proceed*, Safari *Show details → visit this website*.
4. Tap **Start camera**. The pill under the banner turns green: `UNO Q · YOLO … ms · … fps`.

## 4. Run an inspection

1. Hold the phone 20–30 cm above the panel, top of the phone towards the top of the panel.
2. Aim at the ArUco marker (top-left corner) until the scan starts.
3. Follow the arrows: right along the top edge, down the right edge, left along the bottom edge.
   Keep the edge you follow in view (a blue bar shows it is detected; green when it is the
   arrival edge).
4. At the bottom-left corner the result appears: *3 defects found* (defects print) or
   *Panel OK* (blank print). **Download report** saves the JSON inspection report.

During the scan the board's LED beats slowly; each confirmed defect gives n quick flashes;
it stays on when the scan is complete.

## Settings (on the phone)

| Setting | Effect |
|---|---|
| YOLO confidence threshold | Minimum score for a defect (default 0.35). Lower: more sensitive. |
| Print type | Black & white (default) or colour print. Used to find the panel and its edges. |
| Show raw YOLO detections | Draws every detection before tracking, with its score. |
| Next › | Skips to the next path step (fallback if a corner is not detected). |

## Troubleshooting

| Symptom | Cause / fix |
|---|---|
| Page does not load on the phone | Phone and board on different networks, or the network isolates clients. Use the phone hotspot for the board. |
| "The camera needs a secure page" | Open the `https://` address, not `http://`. |
| `UNO Q · disconnected` | The app is not running in App Lab, or Wi-Fi dropped. |
| App fails at start with a missing module | The board had no internet during the first run: connect it and run again. |
| Corners not detected | The panel must lie on a light surface (in black and white the frame is as dark as the cells). Use **Next ›** if needed. |
| Low frame rate | Normal range on the UNO Q is a few frames per second. Hold the phone steady; the overlay follows each processed frame. |

## Test without the board

The same page, pipeline and model run on a computer:

```bash
python -m venv .venv && .venv/Scripts/activate      # Windows (Linux/macOS: source .venv/bin/activate)
pip install -r tools/requirements-dev.txt
python tools/dev_server.py
```

Open the printed address (`https://<computer-ip>:7000`) on the phone.
